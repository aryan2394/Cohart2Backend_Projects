Bahut solid question poocha hai 🔥
Ye real-world system design level ka doubt hai.

Tumne sahi calculate kiya:

1 userId ≈ 12 bytes (MongoDB ObjectId)

280 million followers

280M × 12 bytes ≈ 3.3 GB

MongoDB document limit = 16 MB

Toh clearly ❌ hum ek document ke andar followers ka array store nahi kar sakte.

❌ Galat Approach
{
   _id: kohliId,
   name: "Kohli",
   followers: [id1, id2, id3, ... 280 million]
}


Ye 16MB limit cross karega.

✅ Real World Solution

Hum followers ko separate collection mein store karte hain.

Isko bolte hain:

🔥 Many-to-Many relationship using separate collection

🏗️ Correct Database Design
👤 Users Collection
{
   _id: kohliId,
   name: "Kohli",
   followersCount: 280000000,
   followingCount: 500
}


⚠️ Yahan sirf count store karenge — pura array nahi.
